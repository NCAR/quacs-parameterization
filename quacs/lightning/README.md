# Lightning

Schemes that compute the lightning flash rate and the NOx that lightning makes.

| Scheme | Description | Status |
|---|---|---|
| [`flash_rate_price_rind`](flash_rate_price_rind/) | Flash rate for parameterized convection, Price & Rind (1992) | placeholder |
| [`flash_rate_cummings`](flash_rate_cummings/) | Flash rate for resolved convection, Cummings et al. (2024) | placeholder |
| [`lnox_ott`](lnox_ott/) | Lightning NOx for parameterized convection, Ott et al. (2010) | placeholder |
| [`lnox_decaria`](lnox_decaria/) | Lightning NOx for resolved convection, DeCaria et al. (2000) | placeholder |

Each scheme folder follows the layout in [CONTRIBUTING.md](../../CONTRIBUTING.md).
